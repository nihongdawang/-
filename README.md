📖 项目简介
本项目爬取 北京新发地农产品批发市场 的价格数据，通过多线程并发采集近 300 页菜价信息，并使用 Pandas 进行数据清洗，最终用 Matplotlib 输出多维度可视化图表，帮助直观了解菜价结构与分布。

✨ 功能特性
🚀 多线程并发采集：ThreadPoolExecutor 5 线程并行，大幅提升抓取效率

🔁 重试与超时机制：单页 3 次重试 + 10s 超时，提升弱网环境下的稳定性

🔒 线程安全写入：使用 Lock 保护共享数据，避免并发竞态

🧹 数据清洗：价格类型转换、均价计算、无效值过滤、日期标准化、记录去重

📊 多维可视化：4 类图表（Top10 均价、品类占比、价格分布、产地对比）

📝 中文友好：utf-8-sig 编码输出 CSV，Excel 打开无乱码

🗂️ 结构化落盘：字段对齐、自动写入表头，可直接用于后续分析
